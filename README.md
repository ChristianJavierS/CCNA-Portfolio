## 🛠 Featured Projects

### 1. Redundant Branch Office Deployment (High Availability)
* **Objective:** Design a fault-tolerant branch office network to ensure zero downtime for critical business operations.
* **Technologies:** HSRP (First Hop Redundancy), LACP (EtherChannel), Rapid-PVST+, Cisco 3650 Switches.
* **Key Achievement:** Implemented Layer 2 and Layer 3 redundancy, reducing potential failover time to under 2 seconds.
* **[View Project Details](./Project-1-Redundant-Branch)**

### 2. Secure Site-to-Site VPN (GRE over IPsec)
* **Objective:** Establish an encrypted communication tunnel between two geographically distant corporate offices.
* **Technologies:** IPsec, IKEv1/ISAKMP, GRE Tunnels, Cisco 2911 Routers.
* **Key Achievement:** Secured cross-site traffic using AES-256 encryption while maintaining routing protocol (OSPF) functionality over the tunnel.
* **[View Project Details](./Project-2-Site-to-Site-VPN)**

### 3. Portable Enterprise Virtualization Cluster (Home Lab)
* **Objective:** A "Data Center in a Box" designed for rapid deployment and service isolation.
* **Technologies:** Proxmox VE, Cisco ISR, Meraki MS-Series, Windows Server (AD/DNS), Docker.
* **Key Achievement:** Built a 3-node HA cluster with full VLAN segmentation, isolating IoT and guest traffic from core production servers.
